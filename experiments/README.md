# Reproduction scripts

Each script here regenerates a specific figure or table from the paper
**"Context-Verified, Error-Budget-Aware Decomposition Selection for Toffoli Networks"**
(Bartkiewicz & Tulewicz, arXiv:2606.31791, submitted to *Quantum*).

## Setup

From the repo root:

```bash
pip install -e ".[experiments]"     # brings in qiskit-aer, pytket, mqt.qcec
```

or, without installing, run scripts directly from this directory — the
`_paths.py` shim puts the repo root on `sys.path` automatically.

## Map: paper artefact → driver

| Paper artefact                                    | Driver script                | Output artefact                       | Typical runtime |
|---                                                |---                           |---                                    |---              |
| Fig. `safety` (silent-error rate, gated vs naive) | `safety_experiment.py`       | `safety_results.md`                   | ~30 s           |
| Fig. `budget` (2q-count / infidelity, 12-suite)   | `baselines.py`               | `baseline_results.md`                 | ~5 min          |
| Table (b) (ablation over the verification gate)   | `ablation_b.py`              | `ablation_b_results.md`               | ~1 min          |
| Fig. `device` (5 real-device operating points)    | `sensitivity_sweep.py`       | `fixtures/sensitivity_data.csv`       | ~2 min          |
| Fig. `scale` (12-24 q, verification crossover)    | `scale_eval.py`              | `scale_results.md`                    | ~2 h            |
| Noise validation (density-matrix state fidelity)  | `noisy_sim.py`               | stdout                                | ~5 min          |
| Table `reset` / Fig. `reset` (state-resetting app)| `sync_benchmark.py`          | stdout                                | ~10 min         |
| Table `reset` extension (>12 q via QCEC)          | `sync_scale.py`              | stdout                                | ~30 min         |
| All figure PDFs (from the tabulated results)      | `make_figures.py`            | `fig_safety.pdf`, `fig_budget.pdf`, `fig_device.pdf`, `fig_scale.pdf` | <5 s |

The `.md` / `.csv` outputs are regenerated by the drivers on each run;
only `fixtures/sensitivity_data.csv` ships as a pinned snapshot.
`make_figures.py` is fully self-contained — every numeric value in the
four figures is baked in as a literal from the tabulated results at the
time of submission, so it produces the paper's PDFs on a fresh clone
without running any sweep.

## Files

- `_paths.py` — path-resolution shim (auto-imported by every script)
- `benchmarks.py` — 12-circuit primary suite (table `bench`)
- `large_benchmarks.py` — 20-circuit scale suite (12-24 qubits)
- `naive_relphase.py` — unsafe count-greedy baseline + gated variant
- `fixtures/sensitivity_data.csv` — pinned snapshot of the device sweep
  (checked in so `make_figures.py` runs without re-executing the sweep)

## Optional dependencies

| Dependency                | Needed by                                     | Purpose                          |
|---                        |---                                            |---                               |
| `qiskit-aer`              | `noisy_sim.py`                                | Density-matrix noise simulation  |

| `mqt.qcec`                | `scale_eval.py`, `sync_scale.py`              | Decision-diagram verification    |
