# Reproduction guide

Each empirical panel of the paper (arXiv:2606.31791) has a driver in
`experiments/`. Below is the step-by-step for reproducing every one from
a clean clone.

## Environment

```bash
git clone https://github.com/barkol/toptoffoli
cd toptoffoli
python -m venv .venv && source .venv/bin/activate
pip install -e ".[experiments,dev]"
```

Verify:

```bash
python -c "import toffoli_optimizer; print(toffoli_optimizer.__version__)"
pytest -q
```

## Reproduction commands, in order of runtime

### 1. Fig. `safety` — silent-error rate (~30 s)

```bash
python experiments/safety_experiment.py
```

Writes `experiments/safety_results.md`. The gated column must show
`0/12` silent errors; the naive column must show `6/12` (the paper's
headline safety claim).

### 2. Table (b) — verification-gate ablation (~10 s)

```bash
python experiments/ablation_b.py
```

Writes `experiments/ablation_b_results.md`. Confirms that removing the
gate breaks the same 6 circuits.

### 3. Fig. `device` — 5 real-device operating points (~5-10 min)

```bash
python experiments/sensitivity_sweep.py
```

Writes `experiments/fixtures/sensitivity_data.csv` (overwrites the
pinned snapshot; `git diff` shows any drift).

### 4. Density-matrix noise validation (~5 min)

```bash
python experiments/noisy_sim.py
```

Prints the state-fidelity comparison to stdout. Confirms that the
surrogate ranking translates to real fidelity gains (+0.08–0.15 over
exact-only).

### 5. Fig. `budget` — 12-suite error-budget comparison (~1-5 min; slower with pytket installed)

```bash
python experiments/baselines.py
```

Writes `experiments/baseline_results.md` with per-circuit rows for
Qiskit L3, tket (if installed), exact-only, and the gated selector.

### 6. Table / Fig. `reset` — state-resetting application (~10 min)

```bash
python experiments/sync_benchmark.py
python experiments/sync_scale.py       # 12-24 q, uses MQT QCEC
```

Both print to stdout; `sync_benchmark.py` is the small-width path,
`sync_scale.py` the QCEC-certified path.

### 7. Fig. `scale` — 20-circuit / 12-24 q with verification crossover (~2 h)

```bash
python experiments/scale_eval.py
```

Writes `experiments/scale_results.md` including the exhaustive-vs-QCEC
crossover micro-benchmark. This is the long one — plan for a couple of
hours on a laptop-class CPU.

### 8. Regenerate the four figure PDFs (<5 s)

```bash
python experiments/make_figures.py
```

Writes `experiments/fig_safety.pdf`, `fig_budget.pdf`, `fig_device.pdf`,
`fig_scale.pdf` into `experiments/`. All numeric values are baked into
the script as literals (taken from the tabulated results at the time of
submission), so this step is fully self-contained — you can regenerate
the four vector PDFs on a fresh clone without running any of the
sweeps above.

## Full reproduction, unattended

```bash
python experiments/safety_experiment.py
python experiments/ablation_b.py
python experiments/sensitivity_sweep.py
python experiments/noisy_sim.py
python experiments/baselines.py
python experiments/sync_benchmark.py
python experiments/sync_scale.py
python experiments/scale_eval.py         # slowest
python experiments/make_figures.py
```

Total wall-clock ≈ 3 h on a modern laptop with all optional
dependencies installed.

## Cross-checking against the paper's snapshots

The `_results.md` files are regenerated by the drivers; they are not
checked in. If you want a stable reference, run each driver once on a
clean clone of the `v1.0-submission` tag and keep the output files
locally — subsequent reruns can then be diffed against that snapshot to
detect drift caused by dependency updates.
